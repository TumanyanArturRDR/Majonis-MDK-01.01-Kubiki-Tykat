# Игра на запоминание (Memory / Matching Game)

Простая игра на память на Windows Forms (C#). Нужно открывать по две клетки и находить одинаковые иконки.

## Правила

Правила игры: на поле 16 клеток (4×4).  
Все иконки разбиты на 8 пар и перемешаны.  
Игрок открывает по две клетки за ход.  
- Если иконки совпали — они остаются открытыми.  
- Если нет — через полсекунды они снова скрываются.  

Когда все пары найдены — выводится сообщение о победе и игра закрывается.

## Как я делал

### 1. Создал проект

Создал проект **Приложение Windows Forms (.NET Framework)** на C#.

В свойствах формы поставил:
- `Text = Matching Game`
- Размер удобный для сетки 4×4

### 2. Добавил таблицу, метки и таймер

На форму положил:
- `tableLayoutPanel1` — сетка 4×4, в каждой ячейке по метке `Label` (всего 16)
- `timer1` — таймер для скрытия несовпавших иконок (интервал 750 мс)

У меток настроил:
- `Dock = Fill`
- `TextAlign = MiddleCenter`
- `Font = Webdings`, размер 48
- `BackColor` и `ForeColor` одинаковые (иконки не видны)

### 3. Основные переменные
- `firstClicked` — первая открытая метка
- `secondClicked` — вторая открытая метка
- `random` — для случайной расстановки иконок
- `icons` — список из 8 пар символов (шрифт Webdings)

### 4. Расстановка иконок (`AssignIconsToSquares`)
Метод проходит по всем меткам, выдаёт каждой случайный символ из списка и сразу удаляет его из списка, чтобы пары не повторялись. Иконка скрыта — цвет текста совпадает с фоном.

Вызывается в конструкторе формы.

### 5. Обработчик нажатия на клетку
Логика:
1. Если таймер работает — клики игнорируются.
2. Если метка уже открыта — ничего не делаем.
3. Первый клик — запоминаем метку и показываем иконку.
4. Второй клик — показываем вторую иконку, проверяем победу.
5. Если иконки совпали — оставляем открытыми.
6. Если нет — запускаем таймер, чтобы скрыть их.

### 6. Таймер (`timer1_Tick`)
Через 750 мс скрывает несовпавшие иконки и сбрасывает ссылки на метки.

### 7. Проверка победы
Проходит по всем меткам. Если хоть одна иконка ещё скрыта — игра продолжается. Если все открыты — выводит сообщение о победе и закрывает форму.
